# HoneyVault
Flask + SQLite backend, vanilla JS frontend.

    pip install -r requirements.txt
    python app.py
    # open http://127.0.0.1:5000

Files: app.py (API, crypto), static/index.html (UI).
Demo: register -> log in -> add a card with passphrase "sunshine1" in Honey mode and again in Standard mode -> Attack lab -> run on each.
